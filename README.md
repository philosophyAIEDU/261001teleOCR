종이 학습지·교과서·시험지·판서 사진을 올리면 **고쳐 쓸 수 있는 글자·표·수식·코드**로 바꿔 주는 프로그램이에요.
AI가 **내 컴퓨터 안에서만** 동작해서, 학생 이름이 적힌 문서도 인터넷으로 보내지 않고 변환할 수 있어요.

## 1. 준비물 확인하기

| 항목 | 필요한 것 |
|---|---|
| 컴퓨터 | Windows 10/11 또는 Mac(macOS 12 이상) |
| 메모리 | 8GB 이상 (16GB면 더 좋아요) |
| 저장 공간 | 10GB 이상 비어 있어야 해요 |
| 인터넷 | **설치할 때만** 필요해요 (설치 뒤에는 없어도 돼요) |
| 있으면 좋은 것 | NVIDIA 그래픽카드 또는 Apple M1~M4 Mac → 훨씬 빨라요 |

> 💡 그래픽카드가 없는 일반 PC도 쓸 수 있지만, 사진 한 장에 **1분~몇 분**이 걸릴 수 있어요.
> 학교 컴퓨터라면 프로그램 설치가 허용되는지 먼저 확인해 주세요.

## 2. 프로그램 내려받기

1. 이 저장소 페이지(https://github.com/philosophyAIEDU/261001teleOCR)에서 초록색 **`<> Code`** 버튼을 눌러요.
2. 맨 아래 **Download ZIP** 을 눌러요.
3. 내려받은 ZIP 파일을 **바탕화면**이나 **문서** 폴더로 옮긴 뒤 압축을 풀어요.
   - Windows: ZIP 파일 우클릭 → **압축 풀기** → **압축 풀기** 버튼
   - Mac: ZIP 파일 더블클릭
4. 폴더를 열었을 때 `backend`, `frontend`, `scripts`, `docs` 같은 폴더가 보이면 준비 끝이에요.

> ⚠️ ZIP 파일 안에서 바로 실행하지 말고 **꼭 압축을 푼 폴더**에서 실행하세요.

## 3. 설치하기 (처음 한 번만)

### 3-1. Python 설치

TeleOCR 교실은 **Python** 이라는 무료 프로그램 위에서 돌아가요.

1. https://www.python.org/downloads/ 에 들어가요.
2. 노란색 **Download Python 3.x** 버튼을 눌러 설치 파일을 받아요.
3. 설치 파일을 실행해요.
   - **Windows**: 첫 화면 아래쪽의 **☑ Add python.exe to PATH** 를 **꼭 체크**하고 **Install Now** 를 눌러요.
   - **Mac**: 안내에 따라 **계속 → 설치** 를 눌러요.

### 3-2. TeleOCR 교실 설치

**Windows**

1. 압축을 푼 폴더 → **scripts** 폴더를 열어요.
2. **`install.bat`** 을 더블클릭해요.
3. 파란색 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 눌러요.
4. 검은 창에서 설치가 진행돼요. **10~30분** 걸릴 수 있으니 창을 닫지 말고 기다려요.
   (NVIDIA 그래픽카드가 있으면 자동으로 GPU용으로 설치돼요.)
5. **"설치가 끝났어요!"** 가 보이면 아무 키나 눌러 창을 닫아요.

**Mac**

1. 압축을 푼 폴더 → **scripts** 폴더를 열어요.
2. **`install.command`** 를 **우클릭(또는 control+클릭) → 열기** 를 눌러요.
   그냥 더블클릭하면 "확인되지 않은 개발자" 경고 때문에 안 열릴 수 있어요.
3. 경고 창에서 다시 **열기** 를 눌러요.
4. 설치가 진행돼요(**10~30분**). **"설치가 끝났어요!"** 가 보이면 엔터를 눌러 닫아요.

## 4. 실행하기

| | Windows | Mac |
|---|---|---|
| 실행 파일 | `scripts\start.bat` 더블클릭 | `scripts/start.command` 더블클릭 (처음엔 우클릭 → 열기) |

1. 실행 파일을 열면 검은 창(Mac은 터미널)이 뜨고, 잠시 후 **브라우저가 자동으로 열려요.**
2. 브라우저가 안 열리면 주소창에 **`http://127.0.0.1:8765`** 를 직접 입력하세요.
3. 🚨 **검은 창이 프로그램 본체예요.** 쓰는 동안에는 닫지 마세요(최소화는 괜찮아요).

> 💡 **바탕화면 바로 가기 만들기 (Windows)**: `start.bat` 우클릭 → **바로 가기 만들기** → 만들어진 바로 가기를 바탕화면으로 끌어다 놓으세요.

화면 위쪽 메뉴는 이렇게 생겼어요.

| 메뉴 | 하는 일 |
|---|---|
| **처음 화면** | 기능 소개, 최근 변환 기록 |
| **변환하기** | 사진·PDF를 올려 글자·표·수식으로 바꾸는 곳 ⭐ |
| **시스템 점검** | 내 컴퓨터 상태 확인, AI 모델 내려받기, 샘플 테스트 |
| **활용 가이드** | 교과별 활용 아이디어와 촬영 팁 |
| **모델 소개** | TeleOCR과 개발사 소개, 데이터 안전성 Q&A |

## 5. 처음 실행하면 꼭 할 일: 시스템 점검

처음에는 AI 모델 파일이 아직 컴퓨터에 없어요. 한 번 내려받아야 해요.

1. 위쪽 메뉴에서 **시스템 점검** 을 눌러요.
2. **💻 실행 장치** 칸에서 내 컴퓨터가 어떻게 실행되는지 확인해요.
   - **NVIDIA GPU** / **Apple Silicon** → 빨라요 ⚡
   - **CPU 전용** → 느려요 🐢 (사진을 작게 잘라 넣으면 빨라져요)
3. **🧠 AI 모델** 칸의 **[모델 내려받고 준비하기]** 버튼을 눌러요.
   - 모델 용량이 몇 GB라서 인터넷 속도에 따라 수 분~수십 분 걸려요.
   - 진행률 막대가 끝까지 차고 상태가 **✅ 준비 완료** 가 되면 끝이에요.
4. **🧪 샘플로 테스트하기** 버튼을 눌러요. 영어 지문·표·수식 샘플이 차례로 변환되고 **✅** 가 붙으면 정상이에요.

> 이 과정은 **처음 한 번만** 하면 돼요. 다음부터는 인터넷 없이도 바로 변환할 수 있어요.

## 6. 따라 해 보기 ① 영어 지문을 글자로 바꾸기

가장 결과가 좋은 활용이에요. 처음 연습으로 딱 좋아요.

1. 영어 교과서 지문을 스마트폰으로 찍어 컴퓨터로 옮겨요. (카카오톡 PC버전 "나에게 보내기" 등)
2. 메뉴에서 **변환하기** 를 눌러요.
3. 사진 파일을 **점선 상자 안으로 끌어다 놓거나**, **[파일 선택하기]** 를 눌러 골라요.
   - 화면 캡처(Win+Shift+S)를 했다면 그냥 **Ctrl+V** 로 붙여 넣어도 돼요.
   - 사진이 없다면 아래쪽 **[영어 지문 샘플]** 버튼으로 연습해 보세요.
4. **무엇으로 바꿀까요?** 에서 **📝 글자 뽑기** 카드를 눌러요.
5. **[▶ 변환하기]** 를 눌러요. "AI가 변환하고 있어요…" 가 나오면 잠시 기다려요.
6. 오른쪽에 결과가 나오면 **왼쪽 원본과 비교하며** 틀린 글자를 결과 칸에서 **직접 고쳐요.**
7. **[📋 글자 복사]** 를 눌러 한글·Word·구글 문서에 붙여 넣어요.
   아래쪽 **내보내기** 에서 **Word(.docx)** 파일로 저장할 수도 있어요.

> 💡 활용 예: 복사한 지문에서 핵심 단어를 지워 **빈칸 채우기 문제**, 단어를 뽑아 **어휘 목록** 만들기

## 7. 따라 해 보기 ② 표를 엑셀로 바꾸기

종이 명단·일정표·성적표를 엑셀로 다시 칠 필요가 없어요.

1. **변환하기** 에서 표 사진을 올려요. (연습: **[표 샘플]** 버튼)
2. **📊 표 만들기** 카드를 고르고 **[▶ 변환하기]** 를 눌러요.
3. 오른쪽에 표가 나오면 **칸을 눌러 틀린 글자를 고쳐요.** 합쳐진 칸(병합 셀)도 그대로 유지돼요.
   - 줄이 모자라면 **[➕ 행 추가]**
4. 저장 방법을 골라요.
   - **내보내기 → 📊 Excel(.xlsx)**: 엑셀 파일로 저장 (숫자는 계산 가능한 숫자로 저장돼요)
   - **[📋 표 복사 (엑셀·한글에 붙여넣기)]**: 복사해서 엑셀이나 한글 표에 바로 붙여 넣기
5. 저장한 파일은 보통 **다운로드** 폴더에 있어요.

> 💡 사진에 표 말고 다른 내용이 많으면 **표 부분만 잘라서** 넣으세요([10장](#10-더-정확하게-쓰는-요령) 참고).

## 8. 따라 해 보기 ③ 수식을 한글·Word에 넣기

복잡한 수식을 수식 편집기로 한 땀 한 땀 입력하지 않아도 돼요.

1. **변환하기** 에서 수식 사진을 올려요. (연습: **[수식 샘플]** 버튼)
2. **➗ 수식 변환** 카드를 고르고 **[▶ 변환하기]** 를 눌러요.
3. 오른쪽 **미리보기** 에서 수식이 원본과 같은지 확인해요.
   틀린 곳은 아래 **LaTeX 원문** 칸에서 고치면 미리보기가 바로 바뀌어요.
4. **[📋 LaTeX 원문 복사]** 를 누른 뒤 원하는 프로그램에 붙여 넣어요.

| 프로그램 | 붙여 넣는 곳 |
|---|---|
| 한글(HWP) | 수식 편집기 → LaTeX 입력 기능 |
| Word | [삽입] → [수식] → 수식 입력 방식을 **LaTeX** 로 바꾼 뒤 붙여 넣고 [변환] |
| 구글 문서 | LaTeX 지원 부가기능 또는 수식 도구 |

> 💡 페이지에 수식이 여러 개면 **수식 하나씩 잘라서** 넣어야 정확해요.

## 9. 따라 해 보기 ④ PDF 여러 쪽 한꺼번에 바꾸기

스캔한 시험지·학습지 PDF도 올릴 수 있어요.

1. **변환하기** 에서 PDF 파일을 올려요.
2. **변환할 쪽 선택** 상자가 나타나요.
   - 쪽마다 체크하거나, **[전체 선택]**, 또는 **쪽 범위 입력**에 `1-3, 5` 처럼 적고 **[적용]**
   - 각 쪽의 **[보기]** 를 누르면 왼쪽에서 그 쪽을 볼 수 있어요.
3. 작업 카드를 고르고 **[▶ 변환하기]** 를 누르면 선택한 쪽이 차례로 변환되며 **진행률(2/5쪽 완료)** 이 보여요.
4. 쪽마다 결과를 확인하려면 **[보기]** 로 쪽을 바꿔요.
5. **내보내기** 를 누르면 **모든 쪽의 결과가 한 파일**에 쪽 제목과 함께 저장돼요.

> ⏱️ 쪽이 많으면 오래 걸려요. 처음에는 1~2쪽으로 시험해 보세요.

## 10. 더 정확하게 쓰는 요령

### ✂️ 영역 잘라서 변환 (가장 효과가 큰 방법)

AI는 **한 번에 한 가지(표 하나, 수식 하나)** 만 넣을 때 가장 정확해요.

1. 사진을 올린 뒤 **[✂️ 영역 잘라서 변환]** 을 눌러요.
2. 왼쪽 사진 위에서 **마우스(또는 손가락)로 끌어서** 원하는 부분에 사각형을 그려요.
   - 키보드: 사진을 선택하고 **Enter**(가운데 영역 만들기) → **방향키**(이동) → **Shift+방향키**(크기 조절) → **Esc**(지우기)
3. 알맞은 작업 카드를 고르고 **[✂️ 자른 영역만 변환하기]** 를 눌러요.

### 🗂️ 문서 구조 분석으로 영역 찾기

한 페이지에 제목·본문·표·수식이 섞여 있다면:

1. **🗂️ 문서 구조 분석** 으로 변환하면 왼쪽 사진에 **색깔 상자**(제목·본문·표·수식…)가 표시돼요.
2. 상자 이름표(예: `3. 표`)나 오른쪽 목록을 누르면 그 영역이 **자동으로 잘리고 알맞은 작업이 선택**돼요.
3. **[✂️ 자른 영역만 변환하기]** 를 누르면 끝!

> 🧩 **한 쪽 통째로 변환 (실험)** 버튼은 이 과정을 자동으로 해서 한 쪽 전체를 하나의 문서로 이어 붙여 줘요. 아직 실험 기능이라 결과를 꼭 확인하세요.

### 📸 사진 잘 찍는 법

- **밝은 곳**에서, **그림자가 글자를 가리지 않게** 찍어요.
- 종이와 **정면으로** 찍고, 초점이 맞았는지 확대해서 확인해요.
- 글자가 작으면 **두 장으로 나눠 가까이서** 찍어요.
- 휘어진 책 사진은 **📱 휘어진 사진 분석** 을 먼저 써 보세요. 스캐너가 있다면 스캔 PDF가 가장 좋아요.

## 11. 8가지 작업 카드 한눈에 보기

|---|---|---|---|
| 📝 **글자 뽑기** | 지문·안내문 글자를 옮길 때 | 고칠 수 있는 글자 | 복사, Word, Markdown |
| 📊 **표 만들기** | 명단·성적표·일정표 | 칸마다 고칠 수 있는 표 | + **Excel** |
| ➗ **수식 변환** | 수학·과학 수식 | 수식 미리보기 + LaTeX | 복사, Word, Markdown |
| 💻 **코드 옮기기** | 교재 속 프로그램 코드 | 고칠 수 있는 코드 | 복사, Word, Markdown |
| 🗂️ **문서 구조 분석** | 한 쪽에 여러 요소가 섞여 있을 때 | 사진 위 색깔 상자 | (영역 눌러 다시 변환) |
| 📱 **휘어진 사진 분석** | 비스듬히·휘어지게 찍은 사진 | 사진 위 다각형 상자 | (영역 눌러 다시 변환) |
| 📈 **그래프→데이터표** | 교과서·논문 그래프의 값이 필요할 때 | AI가 추정한 데이터 표 | + **Excel** |
| 🔖 **도장 인식** | 도장(인장) 속 글자 | 글자 | 복사, Word, Markdown |

모든 결과 화면에서:
- 결과는 **직접 고칠 수 있어요.** 고친 내용이 그대로 복사·저장돼요.
- **AI 원본 출력 보기** 를 누르면 AI가 처음 낸 결과를 볼 수 있어요.
- 걸린 시간(예: `12.3초`)이 제목 옆에 표시돼요.

더 많은 교과별 아이디어는 프로그램의 **활용 가이드** 메뉴를 보세요.

## 12. 최근 변환 기록

- **처음 화면** 아래쪽에 최근 변환 결과 **30건**이 남아요. **[결과 복사]** 로 다시 쓸 수 있어요.
- 기록은 **이 컴퓨터의 브라우저에만** 저장되고, 어디로도 전송되지 않아요.
- **[삭제]** 로 한 건씩, **[🗑️ 기록 전체 삭제]** 로 모두 지울 수 있어요.
- 기록을 남기기 싫으면 **☐ 기록 남기기** 체크를 해제하세요.

> 🔒 여러 선생님이 함께 쓰는 컴퓨터라면 사용 후 기록을 지워 주세요.

## 13. 끄는 방법과 다음에 다시 켜기

- **끄기**: 브라우저 탭을 닫고, **검은 창(터미널)을 닫으면** 프로그램이 완전히 꺼져요.
  꺼질 때 올렸던 사진·PDF 임시 파일도 자동으로 지워져요.
- **다시 켜기**: `scripts` 폴더의 **start** 파일만 더블클릭하면 돼요. 설치나 모델 내려받기는 다시 할 필요 없어요.

## 14. 자주 묻는 질문과 문제 해결

<details>
<summary><b>"Python 3.10 이상이 설치되어 있지 않아요" 라고 나와요</b></summary>

Python 설치 때 **Add python.exe to PATH** 체크를 빠뜨렸을 가능성이 커요.
Python 설치 파일을 다시 실행 → **Modify**(또는 제거 후 재설치) → PATH 옵션 체크 → 다시 `install.bat` 실행.
</details>

<details>
<summary><b>브라우저가 열리지 않아요 / 화면이 안 나와요</b></summary>

- 검은 창이 켜져 있는지 확인하고, 주소창에 `http://127.0.0.1:8765` 를 입력해 보세요.
- "이미 실행 중" 오류가 나면 다른 검은 창이 이미 떠 있는 거예요. 그 창을 쓰거나 모두 닫고 다시 실행하세요.
</details>

<details>
<summary><b>"프로그램과 연결이 끊겼어요" 라고 나와요</b></summary>

검은 창(프로그램 본체)이 닫혔어요. `start` 파일을 다시 실행하고 브라우저를 새로고침하세요.
</details>

<details>
<summary><b>"AI 모델을 불러오지 못했어요" 라고 나와요</b></summary>

- 처음 한 번은 **인터넷**이 필요해요. 연결을 확인하고 **시스템 점검 → 모델 내려받고 준비하기** 를 다시 눌러요.
- 학교 방화벽이 `huggingface.co` 접속을 막고 있을 수 있어요. 집이나 다른 네트워크에서 한 번 내려받으면 그다음부터는 인터넷 없이 쓸 수 있어요.
- 저장 공간이 10GB 이상 남아 있는지 확인하세요.
- 시스템 점검 화면의 **자세한 오류 내용**을 펼쳐 캡처해 두면 도움을 받을 때 좋아요.
</details>

<details>
<summary><b>"메모리가 부족해요" 라고 나와요</b></summary>

사진이 너무 크거나 다른 프로그램이 메모리를 많이 쓰고 있어요.
**✂️ 영역 잘라서 변환** 으로 작게 잘라 넣거나, 다른 프로그램(특히 브라우저 탭)을 닫고 다시 시도하세요.
</details>

<details>
<summary><b>너무 느려요</b></summary>

시스템 점검에서 **CPU 전용** 이라고 나오면 원래 느려요(한 장 1분~수 분).
필요한 부분만 잘라서 넣으면 훨씬 빨라져요. 처음 변환할 때는 모델을 메모리에 올리느라 더 오래 걸려요.
</details>

<details>
<summary><b>한국어가 잘 안 읽혀요</b></summary>

이 AI의 공식 지원 언어는 **영어·중국어**예요. 한국어는 품질이 보장되지 않아요.
결과를 원본과 꼭 비교해서 고쳐 쓰고, 영어·수식·표·코드 위주로 활용하시길 권해요.
</details>

<details>
<summary><b>Mac에서 "확인되지 않은 개발자" 라며 안 열려요</b></summary>

파일을 **우클릭(control+클릭) → 열기 → 열기** 로 실행하세요. 한 번 열고 나면 다음부터는 더블클릭으로 열려요.
</details>

<details>
<summary><b>프로그램을 지우고 싶어요</b></summary>

TeleOCR 교실 폴더를 통째로 지우면 돼요. 내려받은 AI 모델은 따로 저장되어 있으니 함께 지우면 공간이 확보돼요.
- Windows: `C:\Users\(내 이름)\.cache\huggingface`
- Mac: 홈 폴더의 `.cache/huggingface` (Finder에서 Cmd+Shift+. 로 숨김 폴더 보기)
</details>

## 15. 꼭 알아 두세요

**⚠️ 한계**
- 공식 지원 언어는 **영어와 중국어**예요. **한국어 인식 품질은 보장되지 않아요.**
- **손글씨** 인식 성능은 공개되지 않았어요. **학생 답안 자동 채점에는 쓰지 마세요.**
- AI 결과에는 오류가 있을 수 있어요. **수업 자료로 쓰기 전에 꼭 원본과 비교**해 주세요.
- 그래프→데이터표 결과는 AI가 **추정한 값**이에요.

**🔒 개인정보**
- 모든 변환은 **내 컴퓨터 안에서만** 이루어지고, 개발사를 포함해 어디로도 전송되지 않아요.
- 인터넷은 **처음 AI 모델을 내려받을 때만** 사용해요.
- 올린 사진·PDF는 임시 폴더에 잠시 있다가 **자동으로 지워져요.**
- 저장한 결과 파일의 보관·공유는 **학교 개인정보 지침**을 따라 주세요.
- 학교·교육청에 외부 소프트웨어 도입 지침이 있다면 사용 전에 확인해 주세요.

**🌐 설치 전에 맛보기**
Hugging Face 온라인 데모(https://huggingface.co/spaces/hugging-apps/teleocr-document-parsing)로 먼저 체험해 볼 수 있어요.
단, **온라인 데모는 파일이 외부 서버로 전송되니** 개인정보가 없는 샘플로만 써 주세요.
