# TeleOCR 교실 설치 가이드 (선생님용)

컴퓨터를 잘 몰라도 따라 할 수 있도록 순서대로 적었어요. 처음 한 번만 설치하면 그다음부터는 **start 파일 더블클릭**으로 바로 쓸 수 있어요.

> 설치에는 인터넷이 필요해요(프로그램과 AI 모델 내려받기). 설치가 끝나면 **인터넷 없이도** 쓸 수 있어요.
> 학교 컴퓨터라면 프로그램 설치가 허용되는지, 교육청 지침이 있는지 먼저 확인해 주세요.

---

## 준비물 확인

- Windows 10/11 또는 macOS 12 이상
- 메모리 8GB 이상 (16GB 권장)
- 저장 공간 10GB 이상 여유
- NVIDIA 그래픽카드나 Apple Silicon(M1~M4) Mac 이면 훨씬 빨라요. 없어도 되지만 느려요.

---

## Windows 선생님

### 1단계. Python 설치하기

1. 인터넷 브라우저에서 <https://www.python.org/downloads/> 에 들어가요.
2. 노란색 **Download Python 3.x** 버튼을 눌러 설치 파일을 내려받아요.
3. 설치 파일을 실행하고, 첫 화면 아래쪽의 **"Add python.exe to PATH"** 에 **꼭 체크**한 뒤 **Install Now** 를 눌러요.

`[스크린샷 자리: Python 설치 첫 화면 - Add python.exe to PATH 체크 위치 표시]`

### 2단계. TeleOCR 교실 내려받기

1. 받은 압축 파일(zip)을 **바탕화면이나 문서 폴더**에 풀어요. (다운로드 폴더 안에서 바로 실행하지 마세요.)
2. 폴더 이름에 한글·공백이 있어도 괜찮지만, 문제가 생기면 `C:\TeleOCR` 처럼 간단한 곳으로 옮겨 보세요.

`[스크린샷 자리: 압축 풀기 - "압축 풀기" 메뉴]`

### 3단계. 설치 파일 실행하기

1. 폴더 안의 **scripts** 폴더를 열어요.
2. **install.bat** 을 더블클릭해요.
3. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 눌러요.
4. 검은 창에 글자가 올라가며 설치가 진행돼요. **10~30분** 정도 걸릴 수 있어요. 창을 닫지 마세요.
5. "설치가 끝났어요!" 가 나오면 아무 키나 눌러 창을 닫아요.

`[스크린샷 자리: Windows PC 보호 창 - 추가 정보 / 실행 버튼]`
`[스크린샷 자리: 설치 완료 화면]`

### 4단계. 실행하기

1. **scripts** 폴더의 **start.bat** 을 더블클릭해요.
2. 잠시 후 브라우저가 열리며 TeleOCR 교실 화면이 나와요. 열리지 않으면 주소창에 `http://127.0.0.1:8765` 를 입력하세요.
3. **검은 창은 프로그램 본체예요.** 사용하는 동안 닫지 말고, 다 쓰면 검은 창을 닫으면 종료돼요.

> 편하게 쓰려면 start.bat 을 우클릭 → **바로 가기 만들기** 후 바탕화면으로 옮겨 두세요.

## Mac 선생님

### 1단계. Python 설치하기

1. <https://www.python.org/downloads/> 에서 **Download Python 3.x** 를 눌러 내려받아요.
2. 내려받은 `.pkg` 파일을 열어 안내대로 설치해요.

### 2단계. TeleOCR 교실 내려받기

받은 압축 파일을 **응용 프로그램**이나 **문서** 폴더에 풀어요.

### 3단계. 설치 파일 실행하기

1. **scripts** 폴더의 **install.command** 를 **우클릭(또는 control+클릭) → 열기** 를 눌러요.
   (그냥 더블클릭하면 "확인되지 않은 개발자" 경고로 열리지 않을 수 있어요.)
2. 경고 창에서 다시 **열기** 를 눌러요.
3. 터미널 창에서 설치가 진행돼요. **10~30분** 정도 걸릴 수 있어요.
4. "설치가 끝났어요!" 가 나오면 엔터를 눌러 창을 닫아요.

`[스크린샷 자리: macOS 우클릭 → 열기 메뉴]`
`[스크린샷 자리: "확인되지 않은 개발자" 경고 창의 열기 버튼]`

### 4단계. 실행하기

1. **scripts** 폴더의 **start.command** 를 더블클릭해요. (처음에는 우클릭 → 열기)
2. 브라우저가 열리지 않으면 주소창에 `http://127.0.0.1:8765` 를 입력하세요.
3. 다 쓰면 터미널 창을 닫으면 종료돼요.

---

## 처음 실행한 뒤 꼭 할 일: 시스템 점검

1. 화면 위쪽 메뉴에서 **시스템 점검** 을 눌러요.
2. **실행 장치** 에서 내 컴퓨터가 GPU·Apple Silicon·CPU 중 무엇으로 실행되는지 확인해요. CPU 라면 느리다는 안내가 나와요.
3. **모델 내려받고 준비하기** 를 눌러요. AI 모델(수 GB)을 한 번 내려받아요. 진행률 막대가 끝까지 차면 완료예요.
4. **샘플로 테스트하기** 를 눌러 영어 지문·표·수식이 잘 변환되는지 확인해요.

`[스크린샷 자리: 시스템 점검 화면 - 장치 정보와 모델 상태]`
`[스크린샷 자리: 샘플 테스트 결과 화면]`

---

## 사용 방법 한눈에 보기

1. **변환하기** 메뉴 → 사진이나 PDF 를 끌어다 놓거나 **파일 선택하기**, 또는 화면 캡처 후 **Ctrl+V**
2. **무엇으로 바꿀까요?** 에서 작업 카드(글자 뽑기, 표 만들기, 수식 변환 …)를 골라요.
3. **▶ 변환하기** 를 눌러요. PC 사양에 따라 수십 초 이상 걸릴 수 있어요.
4. 오른쪽 결과에서 틀린 부분을 직접 고친 뒤 **복사**하거나 **Word·Excel·Markdown** 으로 저장해요.
5. 정확도가 아쉬우면 **✂️ 영역 잘라서 변환** 으로 표 하나, 수식 하나만 골라 다시 변환해 보세요.

`[스크린샷 자리: 변환 화면 - 왼쪽 원본, 오른쪽 결과]`

## 자주 묻는 질문

**Q. "Python 3.10 이상이 설치되어 있지 않아요" 라고 나와요.**
Python 을 설치할 때 "Add python.exe to PATH" 체크를 빠뜨렸을 수 있어요. Python 설치 파일을 다시 실행해 **Modify** 또는 재설치하면서 체크해 주세요.

**Q. "AI 모델을 불러오지 못했어요" 라고 나와요.**
처음 한 번은 인터넷이 필요해요. 인터넷 연결과 저장 공간을 확인하고 시스템 점검 화면에서 다시 시도해 주세요. 학교 방화벽이 Hugging Face(huggingface.co) 접속을 막고 있을 수도 있어요.

**Q. "메모리가 부족해요" 라고 나와요.**
사진이 너무 크거나 다른 프로그램이 메모리를 많이 쓰고 있어요. **영역 잘라서 변환**으로 작게 잘라 넣거나, 다른 프로그램(특히 브라우저 탭)을 닫고 다시 시도해 주세요.

**Q. 너무 느려요.**
GPU 가 없는 컴퓨터는 한 장에 몇 분 걸릴 수 있어요. 필요한 부분만 잘라서 넣으면 훨씬 빨라져요.

**Q. 한국어가 잘 안 읽혀요.**
TeleOCR 의 공식 지원 언어는 영어·중국어예요. 한국어는 품질이 보장되지 않으니 결과를 꼭 확인하고 고쳐 써 주세요.

**Q. 학생 이름이 있는 문서를 넣어도 되나요?**
네. 모든 변환은 이 컴퓨터 안에서만 이루어지고 외부로 전송되지 않아요. 다만 저장한 결과 파일의 보관·공유는 학교 개인정보 지침을 따라 주세요. 여러 사람이 쓰는 컴퓨터라면 처음 화면의 **최근 변환 기록**을 지워 주세요.

**Q. 프로그램을 지우고 싶어요.**
TeleOCR 교실 폴더를 통째로 지우면 돼요. 내려받은 AI 모델은 사용자 폴더의 `.cache\huggingface` (Mac 은 `~/.cache/huggingface`) 안에 있으니 함께 지우면 저장 공간이 확보돼요.
